Informazioni

Sitenotch è un’app mobile per documentare lavori sul campo: lavori, problemi con foto, ricevute, note, rapporti PDF, fatture semplici e backup.

Chieda aiuto o segnali un problema

Apra una segnalazione (issue) sulla pagina GitHub del progetto. Le segnalazioni sono pubbliche, quindi non pubblichi dati personali, dati di clienti, foto di documenti, fatture o file di backup.

https://github.com/contimacfull/sitenotch-legal/issues

Oppure scriva via e-mail per assistenza tecnica, segnalazioni di errori e aiuto nell’uso dell’app: oadsupport@gmail.com. Non alleghi documenti di clienti, fatture o file di backup. Sviluppatore: Alexandru Dan, sviluppatore persona fisica (non una società).

Domande frequenti

  • Dove sono i miei dati? Solo sul suo dispositivo. Non ci sono account né server.
  • Come faccio un backup? Profilo → «Crea backup (dati e PDF)» oppure «Esporta tutti i dati (con foto)». Conservi il file in un luogo sicuro.
  • Come elimino i miei dati? Profilo → «Cancella tutto», oppure disinstalli l’app. I file condivisi o esportati non vengono eliminati dall’app.
  • La dettatura non funziona nella mia lingua. La dettatura funziona solo con il riconoscimento sul dispositivo. Installi il pacchetto lingua nelle impostazioni vocali del telefono oppure digiti la nota.
  • Il testo della ricevuta è sbagliato. Il riconoscimento del testo offre suggerimenti; controlli sempre i campi prima di salvare.
